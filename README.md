# Samalla Amulya Portfolio

A dark, futuristic personal portfolio for an aspiring AI Engineer and Software Developer, built with plain HTML, CSS and JavaScript.

## Features
Preloader, glass navigation, hero with AI network visual, animated stats, skills, filterable projects, timelines, dark/light theme (saved in localStorage), scroll reveal, back-to-top, and a validated mailto contact form. Respects `prefers-reduced-motion`.

## Tech Stack
HTML5, CSS3 (variables, Grid, Flexbox), vanilla JavaScript, Google Fonts (Inter, Space Grotesk).

## Project Structure

```
amulyas-portfolio/

```

## Run Locally
1. Put your photo at `assets/images/profile.jpg`.
2. Open the folder in VS Code, right-click `index.html`, choose **Open with Live Server**.

## Customize
- Replace `href="#"` links (View Project, LeetCode, HackerRank) with real URLs in `index.html`.
- Point each project's GitHub link to its own repository.
- Add dates to the Experience timeline.
- Colors live in the `:root` variables at the top of `style.css`.

## Deploy with GitHub Pages
Push to GitHub, then Settings → Pages → Source: `main` branch, `/ (root)` → Save.
